# Helms Chinese Localization Overlay Guide

Helms localization files live under `helms-overlay/frontend/src/helms`.

## Files

- `terminology.zh-CN.ts`: centralized enterprise terminology.
- `i18n-overrides.zh-CN.ts`: Chinese UI text for the core demo path.
- `helms-ui-text.ts`: reusable Helms UI copy derived from brand and terminology configuration.

## Translation Priorities

1. Login and first-run experience.
2. Dashboard and primary navigation.
3. Digital employee list/detail and chat path.
4. Workspace, tools, skills, and settings labels.

Low-frequency advanced pages may remain partially English during Helms 0.1.
